# Haya logo brief

## Product
Haya is a lightweight desktop terminal and database tool built with Tauri and Svelte.
It is terminal-first, keyboard-driven, and meant to stay small in memory and on disk.

## Name and meaning
"Haya" (はや) is Japanese for "fast". Japanese speakers say "はや!" when something is quick,
as in "wow, that's fast!". The logo should feel quick, but the name should not be literal.

## What to make
Two families, several options each (at least 3 per family):
1. **Compact (square)**: a standalone mark in a rounded square. Used in the window's top bar at 24 × 24 px.
2. **Full**: the mark with the wordmark "Haya" beside it. Used when there is room, at about 24 px tall.

Output as SVG, one file per option, in `docs/logo/` as `compact-1.svg`, `compact-2.svg`, `full-1.svg`, and so on.
Include a light and a dark version of each, as `*-light.svg` and `*-dark.svg`.

## Style
- Soft edges: rounded corners and rounded stroke ends. No sharp points.
- Fast: a sense of motion, such as a slight forward slant or two or three speed lines. Keep it subtle.
- Simple: few shapes, no gradients, no shadows, no fine detail. It must read at 16 px.
- Calm, not loud. It sits next to small toolbar icons, so it should not shout.

## Palette (take the exact values from the app)
- Dark theme: background `#181a1c`, mark `#e7edf5`, accent `#d9b274`
- Light theme: background `#eef0f3`, mark `#1d2227`, accent `#9a6b12`
- Use only one accent colour per option.

## Constraints
- Square variant: the mark must sit in a square with at least 12% padding on every side.
- Full variant: the wordmark uses a single weight, around 650. Avoid decorative fonts.
- No text in the compact variant.
- No trademarks, no imagery of real people or companies.

## Deliverables
- 3+ compact options, 3+ full options, each with light and dark versions.
- A short note per option: the idea, and how it reads at 16 px.
